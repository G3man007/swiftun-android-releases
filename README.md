# SwifTun для Android

Официальные сборки приложения SwifTun для телефонов, планшетов и Android TV. Здесь только готовые APK, исходный код хранится отдельно.

**[Скачать последнюю версию](https://github.com/G3man007/swiftun-android-releases/releases/latest)**

| Файл | Для каких устройств |
|---|---|
| `swiftun-android-<версия>-arm64-v8a.apk` | Большинство телефонов и ТВ-приставок |
| `swiftun-android-<версия>-armeabi-v7a.apk` | Старые и недорогие устройства, многие телевизоры |
| `swiftun-android-<версия>-universal.apk` | Подходит для всех устройств, если не знаете, что выбрать |
| `swiftun-android-<версия>-x86_64.apk` | Эмуляторы и устройства на x86 |

Требуется Android 7.0 или новее. Установленное приложение само проверяет обновления здесь и предлагает их установить. Перед установкой оно сверяет SHA-256 файла и подпись разработчика.

Контрольные суммы лежат в `SHA256SUMS.txt` каждого релиза. Проверить файл: `certutil -hashfile <файл> SHA256` в Windows, `shasum -a 256 <файл>` в macOS и Linux.

Политика конфиденциальности: https://www.swiftun.com/privacy/
